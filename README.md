
This repository is the PreTeXt version of Linear Algebra Done Right,
by Sheldon Axler.  Conversion by David farmer (david@pretext.plus).

There are a small number of hacks to ensure that the numbering of
the HTML follows the numbering of tihe printed book.  These can be
found in `custom-html.xsl` and `assets/customcss.css`.

In addition, the file `frontmatter.html` has some additional content.
Copy the `frontmatter.html` in the main directory into `output/web`
directory between `pretext build` and `pretext deploy`.
